Este departamento reúne os produtos desenvolvidos e comercializados pela Sauerkraut Electronics, com links diretos para suas respectivas páginas em nossa loja virtual.

Os produtos poderão ser adquiridos em diferentes modalidades, conforme sua disponibilidade:

- **Equipamento pronto para instalação:** produto completo, montado e preparado para utilização.
- **Kit para montagem:** conjunto de componentes e materiais necessários para que o próprio cliente realize a montagem.
- **PCB e microcontrolador programado:** placa de circuito impresso acompanhada do microcontrolador com o firmware previamente gravado.

Cada produto contará com uma apresentação própria neste site, incluindo informações detalhadas, características, especificações técnicas e as modalidades disponíveis para aquisição. Os links para nossa loja virtual permitirão ao visitante realizar a compra da opção desejada.
